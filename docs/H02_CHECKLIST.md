## 怎么使用

1. 先搜索 `nc2019-t1-9`，从你已经看过的例子开始。
2. 点“原资料”，按表中的图号、条目或PDF页码定位。SI就是补充材料，PDF页码从文件第1页开始数；链接未自动跳页时手动输入页码。
3. 每一行分别填“一致 / 需更正 / 待定 / 未查”。只查数字也可以，化合物结构不懂就填“待定”，不要把整条记录直接判为通过。
4. 有更正时写出正确值和原文位置；已存在的冲突允许继续待定。
5. 保存Excel发回即可；本表不会自动修改知识库。

测定方式：GC=气相色谱测定；isolated=分离产率。两种产率口径分别保留。原图中的单个结构有时是反应物，产物须结合顶部通式；每条表单已给出提示。

本表覆盖H02的名称/结构、数字与来源对应；涉及H03冲突、H04合并结果、H05条件归属时附提醒，不要求据此猜出唯一答案。
