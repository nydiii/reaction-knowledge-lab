# H03 正文与补充材料产率差异核查教程

本教程用于有机反应知识库的来源核查。读者可以是第一次参与的学生、教师，也可以是接手任务的其他 AI；无需阅读此前聊天，也无需运行代码或准备 API。

任务只有两条记录：**对照论文正文与补充材料，记录各自报告的产率，再判断两处是否能对应到同一反应结果。** 完成核查不要求选出唯一正确的产率。证据不足时，保留两个来源值并写明待定原因，就是有效结果。

## 1. 背景和术语

课程仓库是 [reaction-knowledge-lab](https://github.com/nydiii/reaction-knowledge-lab)。它把文献信息整理为可关联、可检查、可修订的反应记录。H02检查“课程记录是否与某个原文位置一致”；H03进一步检查“不同原文位置的说法如何对应”。

本次只使用一篇论文：*Defying the oxidative-addition prerequisite in cross-coupling through artful single-atom catalysts*，**Nature Communications，2025**，DOI：[10.1038/s41467-025-58579-8](https://doi.org/10.1038/s41467-025-58579-8)。

| 写法 | 含义 |
|---|---|
| Fig.3 | 正文中的图3 |
| SI | Supplementary Information，补充材料，通常是另一个PDF文件 |
| X=Br | 反应通式中X的位置是溴；不能与X=Cl的记录混淆 |
| 4s、4v | 原论文使用的产物编号 |
| nc2025-4s-Br、nc2025-4v-Br | 课程记录编号；nc2025和-Br是课程添加的标记 |
| yield | 产率；这里以百分数记录，不是产物质量或纯度 |
| 待定 | 已明确指出证据不足，尚不作唯一结论 |

## 3. 先查四个数字

以下是课程已有记录中需要复核的值，供定位使用，**不能把本表当作本次核查的证据**。

| 记录 | 正文Fig.3待核对值 | SI第50页待核对值 | 当前课程处理 |
|---|---:|---:|---|
| nc2025-4s-Br | 89% | 80% | 单一产率留空，保留两处来源说法 |
| nc2025-4v-Br | 98% | 99% | 单一产率留空，保留两处来源说法 |

### 步骤A：读取正文图中的值

打开Fig.3，先找到 **X=Br** 区域，然后按原文产物编号定位：

- **4s**：在X=Br区域的第三排第一个。查看结构下方的百分数。
- **4v**：在同一排第四个。查看结构下方的百分数。

行列位置只是辅助，最终以4s、4v编号为准。百分数旁的小写上标a是条件脚注标记，不是产率的一部分。分别记录你实际读到的数字，并保存足以定位的说明或截图。

### 步骤B：读取SI文字中的值

打开SI第50页：

- 页面上方，找名称末尾带 **(4s)** 的段落，化合物名为2-methoxy-1,1'-biphenyl（2-甲氧基联苯）。
- 页面下方，找名称末尾带 **(4v)** 的段落，化合物名为4-methoxy-4'-methyl-1,1'-biphenyl（4-甲氧基-4′-甲基联苯）。

读取各段开头描述制得产物和产率的句子，找到百分数与yield。后面的NMR数据不是本步骤要查的产率。

### 步骤C：逐项填写

| 核查项目 | 我实际读到的值 | 与课程提示值是否一致 | 原文位置或截图 |
|---|---|---|---|
| 4s正文产率 | ______% | 一致 / 需更正 / 未查 | Fig.3，X=Br，4s |
| 4s SI产率 | ______% | 一致 / 需更正 / 未查 | SI第50页，4s段落开头 |
| 4v正文产率 | ______% | 一致 / 需更正 / 未查 | Fig.3，X=Br，4v |
| 4v SI产率 | ______% | 一致 / 需更正 / 未查 | SI第50页，4v段落开头 |

这里填写“一致”，表示**某一行的课程提示值与该行对应的原文一致**，不是说正文与SI两个产率相等。如果实际看到不同数字，填真实观察值并注明文件版本或位置，不要改成提示值来追求一致。

## 4. 再查两处是不是同一结果

数字不同只能先证明“两个位置写了不同的数”。是否构成同一结果的事实冲突，还需要核对它们指向的对象。

| 核查层次 | 具体检查 | 不能据此直接推断什么 |
|---|---|---|
| 产物对应 | 两处产物编号、名称和结构是否一致；尤其注意取代位置 | 同一产物不等于同一次实验 |
| 反应对应 | 卤代底物、硼试剂是否相同；X=Br与X=Cl是否区分清楚 | 同一产物不一定由同一组反应物制得 |
| 条件对应 | 温度、时间、催化剂、投料和规模是否明确对应 | 通用条件不能无依据套到每条结果 |
| 测量对应 | 比较的是同一种产率口径，还是GC产率与分离产率等不同口径 | 两个都带百分号的数不一定可直接比较 |
| 记录对应 | 是否明确报告同一结果、另一次实验、重复实验或合并结果 | 同底物同条件也可能是两次独立实验 |

Fig.3中4s、4v带有上标a，可在SI第26页查看条件a。第50页的产物说明是否明确重述或关联这些条件，需要单独判断；不能因为编号相同就假定所有实验细节相同。

如果能确认产物编号一致，但无法确认底物、条件或具体实验对应关系，应写：**“数字差异已确认；实验对应关系待定。”** 不熟悉结构式时，可完成数字核对，把结构对应留给具备化学知识的核查者。

## 5. 怎样作出结论

| 实际核查情况 | 应填写的结论 | 当前如何处理记录 |
|---|---|---|
| 没有实际打开其中一份资料 | 未查或部分核查，说明缺哪份资料 | 保留已有待核查状态，不声称已复核 |
| 发现课程值读错、定位错或对应了别的条目 | 提出更正，附实际值和原文位置 | 提交有证据的更正建议 |
| 确认数字不同，但无法证明是同一实验结果 | 数字差异确认；实验对应关系待定 | 保留两个来源值，暂不选单一产率 |
| 已有充分证据表明是同一结果，且相同测量口径下数值不同 | 确认来源间存在冲突，尚不能决定正确值 | 保留双方说法和冲突依据 |
| 能证明两处实际是不同实验或不同测量口径 | 不应当作同一个事实强行二选一，说明区别 | 提出分开记录或重新关联的建议 |
| 找到适用于本条结果的可靠勘误或明确说明 | 按新证据提出修订，并保留原说法 | 由知识库维护者形成可追溯修订 |

不要仅因为正文位置更显眼、SI内容更详细、数值更高或两个数更接近某个预期，就选其中一个。也不要把两数平均成新的实验产率。

课程当前的 `record_kind=source_conflict` 是**需要核查的来源差异标记**，不代表已经证明作者写错。`product.yield_percent=null` 表示没有采用单一确认值；两处值保存在 `measurement.yield_claims` 中。这里说明的是现有课程处理，不是要求核查者直接编辑这些字段。

## 8. 完成标准

完成报告时，两条记录都应有明确处理状态：已查到哪些值、哪些位置未查到、能确认到哪一层对应关系、哪些问题仍待定。对已读取内容给出可复查位置。

**“完成这项核查任务”不等于“所有科学问题已经解决”。** 有证据地保留数字差异和不确定性，符合本环节训练来源追溯与知识校验的目标。
