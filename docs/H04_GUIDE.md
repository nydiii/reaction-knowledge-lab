# H04 五次反应合并产物核查教程

本教程面向首次参与核查的学生、教师和接手任务的其他AI，无需阅读聊天记录，也无需运行代码或准备API。

任务是核查一条记录：**JACS 2024论文中产物8的180 mg和93%，描述的是单次实验，还是多次反应合并后得到的产物。** 核查重点是数字的含义和所属范围，不是重新做化学实验。

## 1. 背景和任务对象

论文：*ProPhos: A Ligand for Promoting Nickel-Catalyzed Suzuki-Miyaura Coupling Inspired by Mechanistic Insights into Transmetalation*，**Journal of the American Chemical Society，2024**，DOI：[10.1021/jacs.4c00370](https://doi.org/10.1021/jacs.4c00370)。

课程仓库：[reaction-knowledge-lab](https://github.com/nydiii/reaction-knowledge-lab)。本条课程编号是 **`jacs2024-p8`**。其中p8指论文中的产物8，不是PDF第8页。

| 术语 | 本任务中的意思 |
|---|---|
| 单次投料 | 某一次反应加入的反应物数量 |
| 合并产物 | 多次反应的物料合并后，统一分离或报告的产物 |
| 分离产率 | 分离得到的产物相对于理论产物量的比例 |
| pooled_result | 课程表示“合并结果”的记录类型 |
| 单条记录 | 一个有来源的报告结果；不必等于一次独立实验 |

## 2. 打开资料并定位

打开 [JACS补充材料SI，第121页](https://ndownloader.figshare.com/files/44651241#page=121)。若链接没有自动跳页，在PDF阅读器中手动输入 **121**。页码从该PDF第1页开始计数。

页面上半部分是产物7，下半部分是**产物8**。找到结构图旁的编号8，阅读它下面、NMR数据之前的完整制备说明。不要只截取包含180 mg的最后一个括号。

已下载课程资料时，文件在仓库的 `data/downloads/batch/jacs2024-si.pdf`；固定版本和SHA-256见 [sources.json](../data/batch/sources.json)。链接不可访问时，从论文页面的Supporting Information入口获取；仍无法读取则标为“未查”。

## 3. 顺着段落核对五件事

以下内容是定位提示和课程当前解释，不是核查者已经填写的结果。请以实际打开的原文为证据。

### 第一步：区分一般规模说明和具体示例

段落先说明做过不同规模的合成，随后给出一个使用0.1 mol% Ni的具体示例。找出具体示例从哪里开始，避免把“做过多种规模”理解为这一条记录同时代表所有规模。

### 第二步：找到这个示例的投料

核对是否写有4-溴苯乙酮40 mg、0.20 mmol，以及苯硼酸37 mg、0.30 mmol。这里先描述具体反应如何投料，后面才说明重复和合并。

### 第三步：找到重复次数

查找短语 **“repeated 5 times”**，结合前后文判断重复的是哪个反应。课程目前将这条结果解释为五次反应的合并结果；核查者需要复核次数和上下文，不把数字5理解为产率、规模或样品编号。

### 第四步：找到合并的语义

接着检查 **“combined mixture”** 指向什么。需要确认后面的白色固体及其数量，是由合并物料得到的，而不是又一个独立实验的结果。

### 第五步：确认180 mg、0.93 mmol、93%属于哪一部分

把最后的产物描述与前一句合并说明连起来阅读。当前课程解释是：180 mg、0.93 mmol和93%描述合并后得到的产物；它们没有逐次列出五次实验各自的质量和产率。

| 核查项目 | 待复核提示 | 我实际读到的内容 | 结论与证据位置 |
|---|---|---|---|
| 具体示例的镍用量 | 0.1 mol% Ni |  |  |
| 反应物1及投料 | 4-溴苯乙酮，40 mg、0.20 mmol |  |  |
| 反应物2及投料 | 苯硼酸，37 mg、0.30 mmol |  |  |
| 重复次数 | 课程当前记为5 |  |  |
| 是否明确合并物料 | 是否有合并说明，指向哪些反应 |  |  |
| 合并产物质量 | 180 mg |  |  |
| 合并产物物质的量 | 0.93 mmol |  |  |
| 合并结果的产率 | 93% |  |  |
| 每次实验是否有独立产率 | 该段没有逐次列出，需复核 |  |  |

每行可填“一致、需更正、待定、未查”。只读到了数字但尚未弄清所属范围时，应写“数字读到，单次/合并含义待定”。

## 4. 用一个计算辅助理解

如果已确认按五次反应、每次0.20 mmol底物、底物与产物1:1的计量关系解释，则总理论产物量为：

```text
5 × 0.20 mmol = 1.00 mmol
0.93 mmol ÷ 1.00 mmol × 100% = 93%
```

这与课程对合并产率的解释相容。**它是依赖上述前提的辅助一致性检查，不能替代原文的次数和合并说明。** 不确定每次规模或次数时，先保留疑问。

同样，180 mg除以5得到36 mg，只是算术分摊，不能写成“每次实验实测获得36 mg”。原文没有提供逐次产物量时，各次产率、波动和标准差都不能补造。

## 5. 核查结果怎样影响记录组织

| 核查结论 | 合理的处理建议 |
|---|---|
| 确认描述五次反应的合并结果 | 保留一条合并结果记录，注明次数和合并产物量；单次投料另标范围 |
| 确认有重复，但次数或合并范围仍不清楚 | 保留原文证据，把不明确的部分标为待定 |
| 找到逐次独立结果 | 另附每次结果的证据，再讨论如何关联到合并记录；不要仅复制合并值生成五条记录 |
| 发现课程对180 mg或93%的归属理解有误 | 提出更正，说明原文具体怎样界定范围 |
| 没有取得原文或只看到截断片段 | 标为未查或部分核查，不宣称完整确认 |

课程当前把该条保存为 `pooled_result`，次数记为5，产物质量为0.180 g，产率为93%；反应物0.20/0.30 mmol保留为所述单次投料。这些是待审校的课程记录，不要求核查者直接修改JSON。

导出或下游计算时，不能把单次投料和五次合并产物量当作同一范围进行物料衡算。也不能把93%复制成五个独立测得的产率，或称为已经报告的五次产率算术平均值。

本任务只确认结果粒度与数量范围。该反应具体用了哪套溶剂、镍前体、温度和时间，由 [H05教程](H05_GUIDE.md)继续核查。

```text
请核查一条有机反应结果的记录粒度，提交供人工复核的报告，不修改数据库。

论文：ProPhos: A Ligand for Promoting Nickel-Catalyzed Suzuki-Miyaura Coupling Inspired by Mechanistic Insights into Transmetalation，JACS，2024。
DOI：https://doi.org/10.1021/jacs.4c00370
SI PDF：https://ndownloader.figshare.com/files/44651241
位置：PDF第121页，产物8，结构图下面且NMR数据之前的制备段落。
课程记录编号：jacs2024-p8。

待复核解释：该段先描述0.20 mmol的4-溴苯乙酮和0.30 mmol的苯硼酸投料，随后说明重复五次并合并，180 mg、0.93 mmol、93%属于合并产物。课程按一条五次合并结果保存，而非五条逐次结果。

请实际打开原文，顺序核查：
1. 哪些文字描述一般规模，哪些描述具体示例？
2. 投料量属于单次还是合计？依据是什么？
3. 重复次数和合并范围如何表述？
4. 180 mg、0.93 mmol、93%分别修饰哪个结果？
5. 是否报告了逐次独立质量、产率或统计量？
6. 是否支持课程的记录粒度，仍有什么不确定？

要求：
- 待复核解释不是证据，不得照抄后声称已验证。
- 看不到原文时写未查；语义不明确时写待定并解释。
- 不把合并结果复制成五条独立实测记录，不凭除法补出每次结果。
- 如用0.93/(5×0.20)作辅助核对，必须说明五次同规模及1:1计量关系的前提。
- 本任务不补全未明确绑定的实验条件。

输出：实际查看的资料；逐项数值与语义证据表；是否支持一条合并结果记录；建议处理与未解决问题。每个判断附PDF页码和段落位置，必要时用少量短引文或截图。
```

## 8. 完成标准

报告应分别说明：读到了哪些数字、各数字属于单次还是合并范围、次数如何理解、是否存在逐次结果、建议如何保存。若仍无法确认，明确缺少什么证据即可，不需要为了完成任务而强行判定通过。
