# H05 通用实验条件归属核查教程

本教程面向学生、教师及接手任务的其他AI，无需聊天历史，也无需运行代码。任务是为五条具体反应记录寻找条件依据，并逐项判断哪些字段可以填写、哪些仍应留空。

**“通用过程里出现一个数值”与“这个数值适用于这条结果”是两个需要分别证明的事实。** 当前课程中的空值表示尚未明确绑定，并不等于论文一定没有报告相关信息。

## 1. 什么是条件归属

论文常在前面集中介绍通用实验过程，后面只列产物、投料和产率。“条件归属核查”就是查明某条具体记录是否明确采用该过程，并检查图注、脚注或单条说明中的例外。

| 需要区分的对象 | 含义 |
|---|---|
| 通用过程 | 多个结果可能共用的一套实验步骤 |
| 具体结果 | 某组底物、某种规模、某次或某组实验报告的结果 |
| 明确继承 | 有可定位的文字、图示或脚注证明通用字段适用 |
| 专属说明 | 该条结果另行给出的投料、负载量、条件或测量方式 |
| 待定 | 有候选过程，但尚不足以确定字段归属 |

核查温度、时间、反应溶剂及体积、催化剂前体、催化剂用量、配体、碱等字段。按字段作结论：确认了一个字段，不代表整套条件都已确认。

## 4. 按顺序执行核查

### 步骤A：先抄具体结果的身份和专属说明

打开第3节指定的段落，记下产物编号、两种反应物、底物卤素、硼试剂类型、规模、明确给出的催化剂负载量、产率口径和重复/合并说明。

不要先读通用过程再给记录补字段。例如p8段落中的0.1 mol% Ni是具体线索，应先单独记录；其他字段仍可待定。

### 步骤B：列出候选过程，但先不套用

JACS SI第119页可见两个主要过程，以下只是帮助寻找的摘要，使用前需要自行核对：

| 候选过程 | 溶剂体系 | 镍前体 | 通用段落中的反应温度/时间 |
|---|---|---|---|
| 2-MeTHF/H₂O体系 | 2-甲基四氢呋喃/水 | Ni(cod)₂ | 70°C、16 h |
| i-PrOH体系 | 异丙醇 | NiCl₂·6H₂O | 70°C、16 h |

该页末尾还提到前催化剂21，并指向SI第120页的Scheme S7。它是另一个需要区分的来源，不能把“有一段镍催化说明”当作四条记录共同使用同一镍前体的证据。

正文Scheme 3附近的硼酸酯/硼酸与溶剂体系说明可以帮助筛选候选；仍需检查目标条目的图示、脚注和具体制备。化学上看起来适用，只能算线索，不能代替来源关联。

### 步骤C：找到“这条结果采用这个过程”的连接依据

按下面顺序查找：

1. 具体段落有没有明确写出采用哪个过程、条件或图中示例？
2. Scheme 3中有没有对应产物和底物，哪组条件说明覆盖它，是否有专属上标、颜色、符号或负载量？
3. 图注和周围文字有没有说明适用范围或例外？
4. 段落中的规模、投料、0.1 mol%等线索是否与候选相容？不相容时保留疑点。
5. 对应的是否是这一次分离制备或合并结果，还是同一产物的另一组GC测量？

JACS Scheme 3图注区分GC产率和括号中的分离产率。不要因为两处都出现产物8，就把任何一个图中条件自动绑定到五次合并制备。

**两个候选过程都写70°C、16 h，也不能单凭共同值直接补齐记录。** 先确认目标记录确实受这些过程的适用范围覆盖，且没有相关例外；若只能证明这两个公共字段，可只建议继承温度和时间，继续保留其他字段待定。

### 步骤D：用NC2025的4c练习检查条件上标

先看清一个明确的来源链：Fig.3的 **X=Cl** 区域中，4c产率旁标有上标b；SI第26页条件b给出100°C、20 h。这可以用于理解“条目—上标—条件说明”的对应方式，仍应实际打开图和SI核对。

本任务目标却是 **4c-Br**。SI第46页4c段落报告X=I和Br对应的98%，不是图中X=Cl的95%。

因此应寻找Br结果自己的条件依据。只找到Cl的上标b不够；找不到Br的明确归属时，写“Br条件待定”，保留课程空值。相同产物编号不是跨卤素继承条件的充分依据。

### 步骤E：检查数字是否属于反应阶段

即使找到了正确过程，也要区分所述操作：

- **储备液与单次加入量**：SI第119页先描述配制储备液，再描述取出其中一部分。配液的总体积不是单次反应直接加入的体积。
- **预处理与反应时间**：预先搅拌0.5 h或过夜的描述，不自动等于目标反应的16 h加热时间；“过夜”也不自行换成固定小时数。
- **反应与后处理**：稀释、萃取、洗涤、柱层析中出现的溶剂，不能全部填为反应溶剂。
- **样品溶剂与反应溶剂**：NMR表征中的溶剂描述也不能自动继承。
- **范围与单值**：通用过程里的催化剂用量范围不等于某条记录的具体用量；0.1 mol% Ni也不是0.1 mmol Ni。

这些检查仍属于文献数据解释，不要求实际执行实验步骤。

## 5. 每个字段如何判断

| 证据情况 | 建议状态 | 如何记录 |
|---|---|---|
| 具体结果段落直接给出该字段 | 直接报告 | 填值、单位及该段位置，同时保留适用范围 |
| 有明确连接到通用过程，且该字段没有被专属说明改变 | 有依据继承 | 填值，附“具体条目到过程”的连接证据及过程位置 |
| 只确认部分公共字段 | 部分可继承 | 逐字段提出建议，不宣称整套条件已确定 |
| 仅凭相似底物、同一产物编号或邻近排版推测 | 待定 | 写候选和缺失的连接依据，字段暂留空 |
| 专属描述与候选过程不一致，且未找到例外说明 | 待定，存在差异 | 同时列出两处说法，不自行覆盖 |
| 相应资料打不开或尚未阅读 | 未查 | 明确缺哪一份资料，不推断论文没有报告 |

课程当前四条JACS记录的完整条件未绑定；p8保留了具体段落中的0.1 mol% Ni。NC2025的4c-Br也保留未知条件。这些现状不限制后续有证据的补全：核查者可以提出部分或完整补全建议，由维护者逐项处理。

## 8. 完成标准

五条记录均应有明确核查状态。任何建议补入的值都能追到数值来源和适用依据；尚未确认的字段应说明缺的是什么。允许报告“已查，仍不能确定”，不要求把所有空值填满。
